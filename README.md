# Unihertz Titan 2 Elite

Lightweight research placeholder for a future SableOS Titan 2 Elite bring-up.

## Status

**Parked pending hardware or authoritative firmware evidence.**

Titan 2 Elite is deliberately kept separate from Titan 2. Do not assume that firmware, partition layouts, kernels, boot images, recovery behavior, key layouts, display behavior, or vendor components are interchangeable between the two devices.

## Scope

The repository exists now so evidence can be recorded cleanly when hardware or authoritative firmware becomes available. Until then:

- keep public product/reference material clearly distinguished from device-derived evidence;
- do not copy Titan 2 facts into Elite status fields as if verified;
- do not begin deep reverse engineering without a bring-up blocker;
- do not commit firmware, OTA packages, partition images, dumps, keys, calibration data, or device-specific secrets.

See [docs/STATUS.md](docs/STATUS.md) for the intentionally minimal evidence ledger.
